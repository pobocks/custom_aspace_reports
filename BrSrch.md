# Adding Custom Columns to Browse and Search PagesThis functionality is based on the [Custom Browse and Search Plugin](https://github.com/archivesspace/archivesspace/tree/v4.2.1/plugins/custom_browse_search_column); it uses the same module as described there.Currently, it supports the addition of **Outcome Note** to the _Events Browse_Once the **custom\_aspace\_reports** plugin is installed, and you have re-started the application,* Navigate to Preferences (Global, Repo, or Default - standard prioritization still applies);* Add Outcome Note as an additional column;* Save the Preferences.  Then, when you browse Events, you will see this extra column.
